ClipDex プライバシーポリシー（フル版）

最終更新: 2026年9月16日

このページは、このサイトから入手する ClipDex（フル版）のプライバシーポリシーです。Mac App Store で配布している版については、App Store 版のプライバシーポリシーをご覧ください。

ClipDex（以下「本アプリ」）は、macOS 上でクリップボードの履歴と登録したもの（定型文・画像・動画）を扱うアプリケーションです。本アプリは、クリップボードという性質上きわめて機微な情報に触れます。そのため本アプリは、コピーや貼り付けで取得したデータを一切外部に送信しないという設計を採っています。

1. 外部との通信

本アプリが行うネットワーク通信は、アップデートの確認とダウンロードだけです（第 1-1 節）。ライセンスキーの検証はこの Mac の中で完結し、通信しません。解析ツール・広告・クラッシュレポートの外部送信も組み込んでいません。

本アプリが取得するデータ（クリップボードの内容、履歴、登録したもの、利用統計、ペースト記録、ライセンスキー）のうち、開発者や第三者に送信されるものはひとつもありません。

ライセンスの購入・更新・ライセンスキーの再送は、本アプリではなく、お使いのブラウザでこのサイトを開いて行います。そのときに取り扱う情報は第 1-2 節のとおりです。

1-1. アップデートの確認

本アプリは、新しいバージョンの有無を確認するため、24 時間に 1 回（前回の確認から 24 時間以上たっていれば起動時にも）clipdex.o2z0.com へ通信します（更新の仕組みには Sparkle を使っています）。新しいバージョンがある場合、ダウンロードは確認のうえで github.com（開発者のリリース用リポジトリ）から行います。clipdex.o2z0.com は GitHub Pages で配信しているため、どちらの通信先も GitHub が運営するサービスです。

  • 送る情報: アプリ名・アプリのバージョン・Sparkle のバージョン（HTTP の User-Agent）。お使いの Mac の構成情報を送る Sparkle の機能は無効にしています。クリップボードの内容、履歴、登録したもの、ライセンスキー、その他のデータは送りません
  • 通信先に届く情報: 一般的な Web の通信と同じく、通信先の GitHub には IP アドレスが届きます。GitHub での取り扱いは GitHub のプライバシーポリシーに従います
  • 通信の分離: 確認とダウンロードの通信は、本体アプリとは分離された仕組み（XPC サービス）が行います。本体アプリ自体は外向きの通信権限を持たない設定でビルドしています

自動確認は、設定 → 一般 → 「自動で更新を確認」で無効にできます。無効にした場合、メニューバーの「アップデートを確認…」を選んだときにだけ通信します。

1-2. ライセンスの購入・更新・再送

ライセンスの販売には、次のサービスを使っています。

  • 決済（Stripe / Link） — 決済は Stripe が提供する決済画面で行います。カード番号などの決済情報を開発者が受け取ることはありません。決済画面で入力する情報（メールアドレスなど）は Stripe が取得して注文として記録し、Stripe のプライバシーポリシーに従って扱われます。開発者は Stripe の管理画面で、注文と購入者の情報（購入時のメールアドレスを含みます）を確認できます。発行サーバーは、注文の確認とライセンスキーの送付のために Stripe から注文の内容（注文番号・金額・通貨・割引の有無・購入時のメールアドレスなど）を受け取りますが、メールアドレスそのものは発行サーバーに保存しません（下の表）
  • ライセンスの発行サーバー（Cloudflare） — 開発者が運用する唯一のサーバーで、Cloudflare Workers 上で動いています。ライセンスの購入・更新と、ライセンスキーの再送のときにだけ使われます
  • メールの送信（Resend） — ライセンスキーをお送りするメールは Resend を通じて送信します。Resend には宛先のメールアドレスと、ライセンスキーを含むメール本文が渡ります
  • 不正利用の防止（Cloudflare Turnstile） — 再送フォームでは、自動送信を防ぐために Cloudflare Turnstile を使います。この確認のために、送信元の IP アドレスが Cloudflare に渡ります

発行サーバーが保存する情報は次のとおりです。

内容目的保存期間
注文の記録（Stripe の注文番号、発行したライセンスキー、購入か更新かの区別、発行日時、表示言語、返金の有無、メール送信の状況） 同じ注文に二重にライセンスキーを発行しないこと、ライセンスキーの再送と更新、返金の確認、会計・税務の記録 期限を定めず保存します（削除のご依頼は第 9 節）
メールアドレスから計算したハッシュ値（メールアドレスそのものは保存しません） 再送フォームで入力されたメールアドレスと、注文を照合するため 注文の記録と同じ
更新の手続き中の一時的な記録（入力されたライセンスキーの内容） 更新ライセンスの決済と、元のライセンスの対応づけ 1 時間で削除します
再送フォームの利用回数（メールアドレスのハッシュ値または IP アドレスごと） 短時間の繰り返し送信の制限 メールアドレスのハッシュ値は 10 分、IP アドレスは 1 時間で削除します

ライセンスキーに含まれるのは、購入日・更新期限・注文を識別する値と署名だけで、お名前やメールアドレスは含まれません。

1-3. App Store 版からの乗り換えの受付

App Store 版の Pro を購入済みの方が、フル版の割引を申し込む場合に限り、次の情報をお預かりします。アプリは関与しません（メールでのやり取りです）。

  • お預かりするもの: お送りいただいたメールの本文と、添付の領収書画像に写っている情報（Apple での購入日・品目・名義）
  • 目的: App Store 版 Pro の購入の確認と、割引コードの発行
  • 保存期間: 割引コードの発行から 30 日後に、メールと画像を削除します

1-4. 外国の事業者の利用

第 1-1 節・第 1-2 節のサービスは、いずれも米国の事業者が提供しています。

事業者所在国取り扱う情報位置づけ
Stripe（Link）米国決済画面で入力された情報、注文の内容販売者（マーチャント・オブ・レコード）として、お客様から直接情報を取得します
Resend米国ライセンスキーを送るメールの宛先と本文メール送信の委託先です。Resend のデータ処理契約（DPA）により、委託の範囲外での利用の禁止、通信と保存データの暗号化、再委託先の管理、契約終了後の削除が定められています
Cloudflare米国発行サーバーの記録（第 1-2 節の表）、再送フォームの送信元 IP アドレス発行サーバーを動かす基盤、および不正利用の防止（Turnstile）の提供元です
GitHub米国アップデートの確認とダウンロードの際の IP アドレス配信先のサービスです。開発者はこの情報を受け取りません

米国には、日本の個人情報保護法に相当する包括的な連邦法はなく、州ごとの法律や分野ごとの法律で個人情報が保護されています。米国の制度については、個人情報保護委員会がまとめた外国の制度の調査をご覧ください。開発者は、上記の事業者の規約・データ処理契約と安全管理の措置を確認したうえで利用しています。

乗り換えの申し込み（第 1-3 節）でお送りいただくメールは、国内の事業者のメールサーバーで受信・保管します。

2. 保存する場所

本アプリが保存するデータは、すべてお使いの Mac の内部、App Sandbox によって本アプリ専用に隔離された次の場所に置かれます。

~/Library/Containers/com.o2z0.ClipDex.direct/Data/Library/Application Support/com.o2z0.ClipDex.direct/

iCloud を含む同期機構は使用していません。書き出したファイルやバックアップのファイルは、ご自身が選んだ場所に保存されます。

内容いつ保存されるか既定保持消し方

4. 既定で保存しないもの（オプトイン）

次の 3 つは初期状態ではいずれも無効で、設定画面でご自身が明示的に有効にしたときにのみ保存が始まります。

  • クリップボード履歴 — コピーしたテキストの本文と、その書式データ（RTF / HTML）
  • 画像クリップ — コピーした画像
  • ペースト記録 — 貼り付けたテキストの本文（Pro のみ）

有効にしない限り、コピーや貼り付けの操作から本アプリが保存するのは、回数・文字数・時間帯・内容の種類といった数値とアプリ識別子だけで、内容そのものは保存されません。文字数の計測や内容の種類の判定のために本文を一時的に読み取りますが、判定が終わるとすぐに破棄します。

書式データについて: クリップボード履歴を有効にしている場合、コピーしたテキストの本文に加えて、コピー元アプリがクリップボードに載せた書式データ（RTF / HTML）も保存します。書式データは、コピー元アプリが生成したものをそのまま保存し、本アプリが解析・加工することはありません。

そのため書式データの中には、コピー元アプリが埋め込んだ情報が含まれることがあります。これらは本アプリが付け足すものではありません。

  • コピーした範囲に含まれていたリンクの URL
  • ローカルの一時ファイルのパス（macOS のユーザー名を含みます。開発者の実測では Word / Excel）
  • コピーに使ったアプリの名前・バージョン

保存された書式データも、他のデータと同様に外部へ送信されることはありません（第 1 節）。書式データだけを保存しない設定はなく、クリップボード履歴のスイッチと一体で動作します。サイズの上限は履歴で 1 形式あたり 2MB、登録したものへ移すときは 1 形式あたり 512KB で、超えた場合はその形式の書式だけを保存せず、本文（プレーンテキスト）は通常どおり保存されます。

5. 記録しない仕組み

上記のオプトイン機能を有効にしている場合でも、本アプリは次の仕組みで機微な情報を記録から除きます。

  • 組み込みの除外アプリ — パスワード管理アプリなど 8 件（1Password 7 / 1Password 8 以降 / Bitwarden / KeePassXC / LastPass for Safari / Dashlane / キーチェーンアクセス / システム設定）でコピーした内容、およびこれらのアプリへ貼り付けた内容は保存しません
  • コピー元が付けたマーカーの尊重 — コピー元のアプリが「これは機密情報です」という業界標準のマーカーを付けている場合、クリップボード履歴に本文を保存しません。ただしこの仕組みはコピー元のアプリが対応している場合にのみ働き、すべてのアプリの機密データを検知できるわけではありません
  • ユーザーによる除外アプリの追加 — 設定画面から、起動中のアプリを選んで除外リストに追加できます（組み込みの 8 件に追加されます）
  • 一時停止 — メニューバーから 15 分・30 分・1 時間の間、記録を一時的に止められます（無期限の一時停止はありません）

6. 権限について

本アプリは、macOS のアクセシビリティの許可を求めます。用途は次の 3 つだけです。

  • 自動貼り付け — 選んだ項目を直前のアプリに貼り付けるため、⌘V のキー操作を送ります
  • Paste Stack — 積んだ項目を順に貼り付けるため、貼り付け先で押された ⌘V を検知します
  • ペーストの計測 — ⌘V が押された回数・時間帯・貼り付け先のアプリを数えます

扱うキー入力は ⌘V だけです。それ以外のキー入力は、macOS から通知されても処理せずに捨て、記録・送信することはありません。許可しなくても本アプリは使え、その場合は「選んだ項目をコピーして直前のアプリを前面にする」動作になり、⌘V はご自身で押します（Paste Stack とペーストの計測は止まります）。許可は、システム設定 → プライバシーとセキュリティ → アクセシビリティ からいつでも取り消せます。

7. データの削除

設定 → データ →「すべてのデータ」から、利用統計・クリップボード履歴（画像クリップを含む）・ペースト記録をまとめて削除できます。登録したものとライセンスキーはこの操作の対象外です。登録したものは一覧から個別に、ライセンスキーは設定 → 一般 →「ClipDex Pro」から削除してください。

本アプリをゴミ箱に入れても、第 2 節の保存場所のデータは macOS の仕様により自動では削除されません。すべて消したい場合は、アンインストールの前に「すべてのデータ」と登録したものを削除するか、Finder で第 2 節のフォルダ（~/Library/Containers/com.o2z0.ClipDex.direct）を削除してください。

発行サーバーに保存された注文の記録（第 1-2 節）の削除をご希望の場合は、第 9 節までご連絡ください。削除後は、ライセンスキーの再送と更新ライセンスの購入ができなくなります。

8. App Store 版からの移行

設定 → データ →「App Store 版から移行…」を実行すると、同じ Mac にある App Store 版のデータ（利用統計・設定・クリップボード履歴・画像クリップ・登録したもの・ペースト記録）を本アプリの保存場所へコピーします。この処理は Mac の中だけで行い、通信は発生しません。App Store 版のデータは削除されず、そのまま残ります。移行の前に本アプリにあったデータは、復旧用として、第 2 節の保存場所の隣（同じ Application Support フォルダの中の、com.o2z0.ClipDex.direct.pre-migration- で始まる名前のフォルダ）に残します。このフォルダは「すべてのデータ」では削除されないため、不要になったら Finder で削除してください。
