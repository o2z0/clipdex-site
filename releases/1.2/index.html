ClipDex 1.2 (20742)

1.2 の変更点

フル版の最初のリリースです。

フル版だけの機能

  • 選んだものを直前のアプリにそのまま貼り付け (アクセシビリティの許可が必要。許可しなくても、コピーして元のアプリに戻ります)
  • Paste Stack: 複数を選んで ⇧Enter、または ⌥⇧⌘C で集めはじめると、貼り付け先で ⌘V を押すたびに 1 件ずつ出てきます
  • ペーストの計測と、ペースト記録 (Pro)
  • ライセンスキーによる Pro (購入日から 1 年間に公開された版が使えます)
  • App Store 版からのデータ移行 (設定 → データ →「App Store 版から移行…」)
  • アプリ内からの更新確認 (メニューバー →「アップデートを確認…」)

App Store 版 1.1 からの改良

  • 1〜9 のキーで、上から N 番目をすぐに取り出せます (行の右端に番号)
  • 画像を Finder にファイルとして貼り付け・ドラッグできます。ファイル名は元の名前のまま
  • Finder で 1 つだけコピーしたファイルやフォルダも履歴に残り、ファイルとして貼り戻せます
  • 画像のファイル名でも検索できます
  • バックアップ (Pro) に、登録したもの (画像・動画を含む) も入るようになりました
  • 右クリック「登録したものに保存」で、選んだ複数をまとめて登録できます
  • 同じものをもう一度コピーすると、履歴の先頭に戻ります
  • クイックパネル (⇧⌘V) がカーソルの近くに開きます

What’s new in 1.2

The first release of the full version.

Only in the full version

  • Paste the item you pick straight into the previous app (requires Accessibility permission; without it, the item is copied and you are switched back to the previous app)
  • Paste Stack: select several items and press ⇧Enter, or start collecting with ⌥⇧⌘C, and each ⌘V in the target app pastes the next one
  • Paste tracking, and Paste Records (Pro)
  • Pro via license key (use any version released within one year of purchase)
  • Migrate your data from the App Store version (Settings → Data → “Migrate from App Store Version…”)
  • In-app update checks (menu bar → “Check for Updates…”)

Improvements since App Store version 1.1

  • Press 1–9 to take the Nth item from the top (numbers appear at the right edge of each row)
  • Paste or drag images into Finder as files, with their original file names
  • A single file or folder you copy in Finder is kept in the history and can be pasted back as a file
  • Search also matches image file names
  • Backups (Pro) now include your saved items, including images and videos
  • Right-click “Save to Saved Items” saves all selected items at once
  • Copying the same thing again moves it back to the top of the history
  • The quick panel (⇧⌘V) opens near your cursor
